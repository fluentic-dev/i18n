# Security policy

Fluentic i18n is currently pre-release. Security fixes are applied to the latest source on the default branch until versioned npm releases begin.

Please do not open a public issue for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/fluentic-dev/i18n/security/advisories/new) and include:

- the affected package or component;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

Never include production credentials, private catalogs, or user data in a report. We will acknowledge a complete report as soon as practical and coordinate disclosure after a fix is available.
