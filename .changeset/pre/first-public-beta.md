Publish the first public beta of Fluentic i18n: a typed, framework-independent runtime with React, Next.js, React Native, and web adapters; optional build-time message compilation; and an end-to-end extraction, translation, and catalog workflow.

This beta also adds JSONL, JSON, CJS, and MJS catalog output, ordered translator fallbacks, compiled-catalog loading in the regular runtime, deterministic message hashing, conflict recovery, and configurable rich-message line breaks.
